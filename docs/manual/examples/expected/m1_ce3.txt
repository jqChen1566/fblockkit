fBlockKit -- the f-block calculation toolkit (input generation + characterisation analysis; the core runs no calculations -- an optional execution bridge, off by default, can run a generated input when explicitly asked)

Available functions:
   1  Check-up and characterisation (read an ORCA or Gaussian output -> analysis + diagnosis report)
   2  Coordination geometry and symmetry hints (read an XYZ structure)
   3  Generate an ORCA input (system profile -> input file + run guidance)
   4  Basis-set / ECP recommendation (element/valence/targets)
   5  Search the tool index (keywords)
   6  Tool onboarding notes (by index id)
   7  Cross-level solution consistency (records JSON input)
   8  Save this session as a script
   9  SCF rescue (triage + corrected input files)
  10  Crystal-field fit (levels + coefficients JSON)
  11  Point-charge crystal-field estimate (read an XYZ structure + charges)
  12  Exact active-space analysis (CASSCF output + FCIDUMP: four-state entropy, environment spin entropy, atomic-term check; optional orca_2json exports)
  13  Orbital-space comparison (two orca_2json exports: subspace fraction and space-change SVD)
  14  AVAS target projection (an orbital export + a target AO shell -> active-space size)
  15  Orbital portrait (an export -> occupation, bonding label, shell composition, extent)
  16  Magnetic-doublet criterion (a Kramers-doublet table or an engine SINGLE_ANISO output -> g_T * theta_3 and the QTM line)
  17  Cross-structure orbital mapping (a manifest of exports -> consistent active spaces along a path)
  18  WASP guess transfer (neighbour orbitals -> an interpolated, gbw-ready mkl for a geometry series)
  19  Dipole-moment candidate batch (a structure -> prep + CASCI inputs + manifest for the DM-AS scan)
  20  Dipole-moment selection (the batch outputs + a reference -> the active space by DM-AS)
  21  APC orbital ranking (an export with the Fock exchange block -> ranked active space at a CSF cap)
  22  ASS1ST round-1 input (a structure + an initial active space -> a CASSCF+FIC-NEVPT2 round)
  23  ASS1ST selection round (a NEVPT2-density export -> quasi-NOON tables + the next round's input)
  24  QICAS active-space optimization (an FCIDUMP -> F_QI-minimized orbitals and the CASCI check)
  25  AEGISS selection (entropy screening + an AO projection -> a compact active space)
  26  TNASS subset selection (an FCIDUMP -> the S2-maximizing orbital subset, or the best-k energy sweep)
  27  DeltaSCF / MOM excited-state SCF input (a structure + an excitation spec -> an input)
  28  RAS / ORMAS model-space input (a structure + a partition mask -> an ORCA input)
  29  Perturbed multistart batch (a converged reference mkl + its input -> restart inputs)
  30  Imaginary-mode displacement (a frequency output + its input -> restart inputs)
  31  CASSCF state data (a property file -> per-state energies and transitions)
  32  pysisyphus input (a structure + a method -> a PES-exploration YAML)
  33  pysisyphus run report (a run directory or console capture -> cross-checked record)
  34  Judd-Ofelt intensity parameters (a transition dataset -> Omega_2/4/6 and radiative quantities)
  35  pNMR pseudocontact shifts (a susceptibility run file + a structure -> per-nucleus PCS; optional Bleaney comparator)
  36  Magnetic relaxation and QTM (an ORCA output with SINGLE_ANISO or MAGRELAX -> the barrier estimate and tau(T))
  37  Core-excited spectra XAS/XES/RIXS (a ROCIS output -> the spectra table and the edge branching ratio; a structure -> ROCIS XES, CAS-CI XAS or RAS-CI XES inputs)
  38  Ab initio ligand-field analysis (an AILFT output -> LF splitting, Slater-Condon/Racah parameters and the fit quality)
  39  Polynuclear magnetism (a POLY_ANISO output -> per-center data, the exchange decomposition and the chiT summary)
  40  Hyperfine and EFG parameters (an EPRNMR output -> the A tensor, the EFG principal values and Rho(0))
  41  Magnetic entropy and magnetocaloric effect (levels or POLY_ANISO M(H,T) -> S_mag(T) and -DeltaS(T,H))
  42  xTB pre-screening run report (an xtb capture -> run facts, frequencies and the upgrade notes)
  43  CREST conformer ensemble (a run directory -> the sorted table with Boltzmann weights)
  44  MOKIT automr input (a structure + options -> a Gaussian-style .gjf with the mokit{} block)
  45  MOKIT automr run report (an automr output -> the stages, the energy chain and the active space)
  46  Quantum-tunnelling relaxation prediction (a SINGLE_ANISO output -> tau_QTM and U_eff(T); optional neighbour table for the dipolar model)
  47  AOP rotation guess (a reference active space + a target export -> a gbw-ready mkl)
  48  PiOS pi-orbital active space (a pi-system definition + an export -> the pi orbitals and a gbw-ready mkl)
  49  Cross-run state tracking (an ordered run sequence + a target root -> the per-step root-matching table)
  50  Run a generated input with ORCA (the optional execution bridge; off by default, acts only when asked)
   0  Quit
