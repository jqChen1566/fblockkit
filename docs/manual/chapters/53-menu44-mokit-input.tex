\chapter{MOKIT automr input (menu 44)}
\label{ch:menu44}
\menulabel{44}

\section{Purpose}

MOKIT's \code{automr} is a black-box multireference driver (HF $\to$ UNO
$\to$ GVB $\to$ CASCI/CASSCF).  This menu writes the input it consumes:
one Gaussian-style \code{.gjf} carrying the \code{mokit\{\}} block.

\section{What you need}

A structure source (XYZ / ORCA input / ORCA output), the method (default
\code{CASSCF}; write \code{CASSCF(6,6)} to pin the active-space size),
the basis (default \code{cc-pVDZ}), an optional comma-separated
\code{mokit\{\}} option list, charge, multiplicity, memory and cores.
The generator's own acceptance run used \code{GVB\_prog=Gaussian}.

\section{Walkthrough}

The example generates the water input and prints the file and the
run-side guidance (the environment chain that the measured run used:
\code{MOKIT\_ROOT}, \code{PYTHONPATH}, the plain \code{python} command,
\code{g16root}/\code{GAUSS\_SCRDIR}).

\section{What you get}

Two files next to the source: \code{<name>\_automr.gjf} (the generated
input) and \code{<name>\_automr.fbk.md} (the report, repeating the file
and the guidance).

\section{Conventions, cross-checks and boundaries (measured)}

\begin{readbox}
\begin{itemize}
  \item \textbf{The active-space size is pinned only if written}: a bare
    \code{CASSCF} lets automr determine the size from the GVB
    natural-orbital occupations (threshold 0.02); \code{CASSCF(6,6)}
    fixes it.  Both modes are covered by the shipped probes.
  \item \textbf{\code{GVB\_prog}} accepts GAMESS (the program's default),
    Gaussian and QChem only; the generator normalises the value and
    refuses anything else with the reason (PySCF is not a GVB backend;
    manual section 4.4.10).  On a machine without GAMESS, write
    \code{GVB\_prog=Gaussian}.
  \item \textbf{The option list is shape-checked and passed through}
    (comma-separated \code{key=value} entries or bare flags such as
    \code{charge}/\code{cart}); the program lower-cases and merges the
    entries itself.
  \item \textbf{The run environment is version- and NumPy-bound} for the
    prebuilt MOKIT packages (extension modules compiled for one CPython
    and against NumPy 1); two measured import failures (an anaconda 3.13
    python; a 3.10 with NumPy 2) are recorded in the fixture README.
  \item \textbf{Measured boundary}: on this group's machines an
    automatically chosen GVB(5) (an N2 probe) crashed Gaussian 16; the
    shipped acceptance runs are the water probes, which reached
    \code{Normal termination}.
\end{itemize}
\end{readbox}
