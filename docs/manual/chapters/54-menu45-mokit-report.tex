\chapter{MOKIT automr run report (menu 45)}
\label{ch:menu45}
\menulabel{45}

\section{Purpose}

Reads an \code{automr} run back: the program-path survey, the run
settings and merged \code{mokit\{\}} options, the strategy table, the
stage sequence, the energy chain, the automatically determined active
space, the Radical-index tables and the termination state.

\section{What you need}

The captured automr output (\code{automr x.gjf > x.out}).

\section{Walkthrough}

The example reads the acceptance run of the menu-44-generated input
(CAS(4e,4o) automatically determined; GVB on a Gaussian~16 backend,
CASSCF on PySCF; three Radical-index tables; \code{Normal termination of
AutoMR}).

\section{What you get}

The report \code{<output>.mokit.fbk.md}: the version and backend survey
(\code{NOT FOUND} entries listed as measured), the settings line, the
merged options, the final strategy flags, the stage sequence, the energy
chain (\code{E(RHF)/E(UHF)/E(GVB)/E(CASCI)/E(CASSCF)} in order, with
\code{<S**2>} where the engine printed it), the GVB order, the
\code{CAS(ne,no)} selection, the radical-index tables and the termination
line.

\section{Conventions, cross-checks and boundaries (measured)}

\begin{readbox}
\begin{itemize}
  \item \textbf{The strategy table is reprinted on updates}; the report
    quotes the last printing (the effective strategy).
  \item \textbf{Consecutive energy-chain entries are different
    wave-function levels} (HF $\to$ GVB $\to$ CASCI $\to$ CASSCF), not a
    convergence error.
  \item \textbf{The active space on the CASSCF line is the automatic
    selection} unless the route pinned the size; both shipped probes
    report the automatic \code{CAS(4e,4o)} of water.
  \item \textbf{Without the closing \code{Normal termination of AutoMR}
    line every number is partial}; the report says so explicitly.
  \item \textbf{Stated boundary}: the natural-orbital \code{.fch} side
    products are listed for the audit trail; their contents are outside
    this report.
  \item \textbf{Citation form}: ``Jingxiang Zou, Molecular Orbital Kit
    (MOKIT)'' -- the project has no program paper.
\end{itemize}
\end{readbox}
